# RadarLive

Ecranul de după trimiterea cererii: Jobzerii apar pe inele de 5/10/15 minute, ofertele sosesc live și clientul poate alege direct.

## Anatomie

- Harta cu raza care se rotește (3,2 s), inele punctate cu minutele, semnul Jobzee în centru.
- Pinii Jobzerilor: poză 48 px; când trimit oferta primesc cerc `brand` și eticheta cu prețul.
- Foaia de jos: mascota (caută → potrivește → bravo), „N Jobzeri găsiți · M oferte”, bara de progres, top 3 rânduri sortate.
- Sortare: Cel mai rapid / Potrivire skill / Preț ofertă. Rândurile cu ofertă au butonul „Alege”.
- Comutator „Alege automat prima ofertă Gold sub X lei” pentru urgențe.

## Reguli

- Poziția pe hartă e după timpul de sosire, nu poziția reală a Jobzerului (confidențialitate).
- Prețurile afișate sunt ofertele Jobzerilor; taxa de 15% se arată la alegere.
- Notificările se cer aici, o singură dată: „Te anunțăm când vin ofertele?”.
