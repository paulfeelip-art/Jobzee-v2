# Skeleton

Forma gri a conținutului care se încarcă, cu un luciu care trece peste ea. Înlocuiește spinner-ul pe orice listă.

## Reguli

- Aceeași formă ca rândurile reale (avatar rotund, două linii de text, preț în dreapta), ca ecranul să nu sară când apar datele.
- Culoare `surface-3`, luciu `surface`, buclă de 1,4 s. Cu „Reducere mișcare”: fără luciu.
- Peste 8 secunde fără date: mesajul „Durează mai mult decât de obicei” și butonul „Reîncearcă”.
