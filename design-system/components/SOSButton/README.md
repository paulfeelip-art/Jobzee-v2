# SOSButton

Butonul de urgență din ecranul Siguranță, pe durata unei sarcini active (Jobzer și client).

## Reguli

- Roșu `#FF3B30`, 140 px, text alb „SOS”, cu puls continuu.
- Se ține apăsat 3 secunde; un cerc alb se umple ca să nu se declanșeze din greșeală. După 3 s: apel 112 + locația exactă + echipa Jobzee anunțată.
- După declanșare: „Am apăsat din greșeală” pentru anulare imediată.
- Alături: traseu partajat cu o persoană de încredere și alertă discretă către echipă.
- Butonul de intrare („Siguranță”, scut roșu) e vizibil permanent pe ecranele de sarcină activă.
