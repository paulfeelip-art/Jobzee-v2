# Brand

Logo-ul oficial Jobzee în cele trei forme: orizontal, stivuit și doar semnul (pinul cu cheie).

## Reguli

- Se scalează doar după înălțime; lățimea e automată, ca să nu se deformeze semnul.
- Antet: logo orizontal la 28–32 px înălțime. Splash: stivuit, 120–160 px. Avatar Jobzee și notificări: semnul la 20–28 px.
- Același fișier pe fundal deschis și închis. Nu se pune pe portocaliu (semnul dispare).
- Spațiu liber minim în jur: jumătate din lățimea semnului.
- Pentru producție: master SVG. Fișierele actuale sunt raster din materialele primite.
