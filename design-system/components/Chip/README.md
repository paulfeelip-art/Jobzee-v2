# Chip

Pastilă mică pentru alegeri rapide: categorii, etichete de recenzie, răspunsuri rapide în chat.

## Variante

- `jz-chip`: fundal `surface-2`; selectat (`aria-pressed="true"`) devine `brand` cu text `ink-on-brand`. Pentru alegeri multiple.
- `jz-chip--outline`: contur `brand`, text `brand-text`. Răspunsuri rapide de la Jobzee și din chat; dispare după alegere.

## Reguli

- 40 px înălțime, `radius-pill`, text 15 px. Se așază pe rânduri cu `space-2` între ele.
- Etichete de 1–3 cuvinte, la persoana I când răspunde omul: „Da, aici”, „Sunt acasă”.
