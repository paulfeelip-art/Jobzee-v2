# Mascot

Mascota oficială în stările aplicației: o poză pentru fiecare situație, unele animate (12 fps).

## Reguli

- Fără față: emoția o dă poza, nu se adaugă ochi sau gură. Nu se redesenează și nu se recolorează.
- O singură mascotă pe ecran, la 70–140 px înălțime, în stări goale, erori, succes și lângă Jobzee.
- Niciodată pe butoane, în liste sau lângă sume de plătit.
- Animatele (gândește, caută, potrivește, ascultă, succes) se înlocuiesc cu primul cadru la „Reducere mișcare”.
- Pozele `card-*` au fundalul lor crem; se pun pe `#FBF1E3` și în dark.
