# StatusPill

Etichete mici de stare: sarcina live, verificări, niveluri și starea unei oferte.

## Variante

- `jz-pill--live`: `brand-soft` + punct portocaliu care clipește. „Pe drum · 6 min”, „În lucru”.
- `jz-pill--ok`: `success-soft` + `success-text`. „✓ Identitate verificată”.
- `jz-pill--neutral`: `surface-2` + `ink-2`. „Altul ales”, „Promovat”.
- `jz-pill--tier`: insigna de nivel lângă nume: Start, Plus, Gold, Black.

## Reguli

- 28 px (22 px insigna de nivel), text 12 px bold. Maximum 3 cuvinte.
- Starea nu se spune doar prin culoare: textul o spune mereu.
